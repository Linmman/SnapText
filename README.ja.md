> ホットキーを押して、取りたい文字をドラッグで囲むだけ — 離した時点で**すでにクリップボードに入っています**。処理はすべてローカル・オフラインです。

## なぜ作ったか

画面上の文字には選択できないものがたくさんあります。動画の字幕、チャットの通知、ゲームの UI、PDF、エラーダイアログ。従来は「スクリーンショット → 別のアプリに貼る → 認識ボタン → コピー」という手順の連鎖でした。

SnapText はそれを 1 手に縮めます：**ホットキー → 囲む → 貼る**。[Ditto](https://ditto-cp.sourceforge.io/) や Windows のクリップボード履歴（`Win+V`）と組み合わせれば、「この一文・この URL を残したい」が反射でできるようになります。

- **既定でオフライン**：認識は手元で完結（PP-OCRv5）。アップロードなし、API キー不要、アカウント不要。
- **中国語の動画向けに調整**：Douyin / Bilibili の字幕や一瞬流れる URL はまさに難所です。中国語に最適化したエンジンで読み取り、リンクは壊さず修復します。
- **邪魔をしない**：トレイに常駐し、取得時にメインウィンドウを出さず、終わったら元のウィンドウにフォーカスを戻します。次の操作はそのまま `Ctrl+V`。

## ダウンロードとインストール

| | |
|---|---|
| 対応 OS | Windows 10 / 11（64 ビット） |
| ダウンロード | [Releases](../../releases) → 展開 → `SnapText.exe` を実行 |
| インストール | 不要（ポータブル）。書き込むのは `%LOCALAPPDATA%\SnapText` と `ピクチャ\SnapText` だけです |
| .NET | 不要 — ランタイム同梱の自己完結ビルドです |
| サイズ | 展開後およそ 210MB（.NET ランタイムとオフライン OCR モデルを含む） |

初回起動時に SmartScreen の警告が出ることがあります（コード署名なしの個人オープンソースプロジェクトのため）。リリースノートの SHA-256 で照合するか、ご自分でビルドすることもできます。

## 使いかた

1. `SnapText.exe` を実行すると、トレイに青い **字** アイコンが出ます。
2. `Ctrl+Alt+Q` を押して文字を囲み、離します。あとは `Ctrl+V` で貼るだけ。
3. トレイアイコンは、左クリックでもう一度取得、右クリックでメニュー（前回の範囲・連写取得・**最近の取得**・設定など）。

| ホットキー | 動作 |
|---|---|
| `Ctrl+Alt+Q` | 取得：画面を凍結 → 範囲を囲む → クリップボードへ |
| `Ctrl+Alt+R` | **前回の範囲**をもう一度取得（囲み直し不要。字幕の位置が決まっている場面に） |
| `Ctrl+Alt+B` | **連写取得**：数フレームを採取して最もきれいな 1 枚を採用。**再生中**の動画のように文字が動く場面向けで、単発より約 0.5 秒遅くなります |
| トレイ左クリック | `Ctrl+Alt+Q` と同じ |
| `Esc` / 右クリック | 範囲選択をキャンセル |

3 つのホットキーは**設定**で変更でき、空欄にすれば完全に無効化できます（使わないキーを占有させない）。設定ではほかに、OCR エンジン、静かにコピーするか編集可能な結果ウィンドウを出すか、複数行を 1 文にまとめるか、リンクを開くプログラム、スタートアップ登録、直近 200 件の取得履歴を保存するか、スクリーンショットの同時保存を選べます。

## できること

- **ホットキー 1 つで取得**：先に画面を凍結するので、再生中の動画と競争になりません。完了後はフォーカスが元のウィンドウに戻ります。
- **嘘をつかないコピー**：書き込みはリトライし、読み戻して確認します。失敗すればはっきり知らせます（「コピーしました」と出たのに貼れない、が起きません）。
- **最近の取得をワンクリックで**：取得した結果（連写・QR 含む）はローカルに最大 200 件保存されます（連続する同一内容は自動でスキップ）。トレイ右クリック →「最近の取得」に最新 15 件が並び、クリックするとクリップボードに戻ります。ポップアップも設定も不要で、同じメニューからオフ・消去もできます。
- **QR / バーコード**：コードを囲むと内容をデコードしてコピーします（OCR と並行実行なので待ち時間は増えません）。
- **リンク処理**：結果に URL があれば通知に **リンクを開く** が出ます（既定のブラウザ、または設定で指定したプログラム）。結果全体がリンクなら、OCR が入れた余分な空白を除いて `https://` を補完しますが、**説明文が続く場合は原文を一切変更しません**。
- **中国語の整形**：OCR が中国語の間に入れる不要な空白を除去。複数行を 1 文にまとめるかは選べます。
- **OCR エンジン 2 系統**：既定は PP-OCRv5 のローカル実行（中国語とラテン文字の混在、URL、コードに強い）。Windows 標準 OCR は高速なフォールバックとして使えます。自動でも固定でも可。比較の実測値は [docs/Development.md](docs/Development.md)。
- **マルチモニター・混在 DPI**：モニターごとにオーバーレイを持ち、座標は物理ピクセルで処理します。

## コマンドライン（任意）

スクリプト、ショートカット、AutoHotkey 向けです（`--help` はありません。一覧はこれで全部です）：

```powershell
SnapText.exe --grab                                        # 起動中のインスタンスに取得させる
SnapText.exe --grab-region 100,900,1200,200 --out r.txt    # 固定範囲を取得（字幕帯など）
SnapText.exe --ocr shot.png --engine ppocr --out r.txt     # 画像を OCR（トレイ不要）
SnapText.exe --scan qr.png                                 # QR / バーコードをデコード
SnapText.exe --qr "https://example.com" --out qr.png       # QR を生成
SnapText.exe --capture --out screen.png                    # デスクトップ全体をキャプチャ
SnapText.exe --history list --n 20                         # 最近の取得（新しい順）
SnapText.exe --history search <text>                       # 取得履歴を検索
SnapText.exe --history clear                               # 取得履歴を消去
```

オプション：`--engine auto|ppocr|windows`、`--no-merge`（改行を保持）、`--no-copy`（クリップボードを触らない）。

## 困ったときは

**[docs/Troubleshooting.md](docs/Troubleshooting.md)**（中国語）に、ホットキーの衝突、認識精度、クリップボードの失敗、SmartScreen、トレイアイコンが見えない、完全なアンインストール方法などがまとまっています。よくあるのは：

- **ホットキーが効かない**：他のソフトが使用中のことがほとんど（起動時に知らせます）。設定で変更するか空欄で無効化を。ロック画面ではどのホットキーも動きません（Windows の仕様）。
- **認識が甘い**：エンジンを PP-OCRv5 にし、文字の周りをきつめに囲み、可能なら動画を一時停止。
- **通知が画面を隠す**：通知そのものか右上の ✕ をクリックすればすぐ消えます（自動でも消えます）。
- **ログ**：`%LOCALAPPDATA%\SnapText\logs\`。

## 既知の制限

- キャプチャは GDI 経由：HDR ディスプレイや排他的フルスクリーンのゲームでは色が変わる／取得できないことがあります。
- モニターをまたぐドラッグでは、選択範囲のハイライトは開始したモニターでしか完全には描画されません（取得データ自体は正しい）。
- ロック画面では動作しません（Windows 側の仕様で、本ツール固有の問題ではありません）。
- 装飾的なフォント、極端に低いコントラスト、動くオーバーレイに隠れた文字は、まだ OCR が失敗します。
- 連写取得はスクリーンショットを保存しません。
