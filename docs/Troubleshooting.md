# 常见问题与排查

> 排查第一步永远是看日志：`%LOCALAPPDATA%\SnapText\logs\app-yyyyMMdd.log`
> 在资源管理器地址栏粘贴 `%LOCALAPPDATA%\SnapText\logs` 即可打开。

## 热键没反应

1. **热键被占用**：启动时如果注册失败，会弹一条提示。进「设置」换一个组合（避开微信 `Alt+A`、QQ `Ctrl+Alt+A`、Snipaste `F1`、天若 `F4` 等常见键位）。
2. **有程序以管理员身份运行**：UIPI 机制下，普通权限的热键无法在管理员窗口内生效。解决：以管理员身份运行 SnapText（不推荐）或在该程序里改用「先复制文本」的方式。
3. **桌面处于锁屏 / 安全桌面**：Windows 会拦截热键与输入，锁屏下任何工具都收不到。解锁后再试。
4. **托盘图标还在吗**：如果图标没了，说明进程已退出 —— 看日志尾部是否有异常；重新启动即可。

## 识别不准 / 网址认错

- 在「设置 → 识别引擎」里确认是 **PP-OCRv5 本地**（推荐）。系统 OCR 对英文/网址明显更差（例如把 `bilibili` 认成 `biIibiIi`）。
- 框选**紧贴文字**、少留背景；文字太小就重新框一次（工具会自动放大小图）。
- 视频暂停一帧再取字，比播放中取字稳。
- 提示里出现"识别可能不准，建议核对"时，说明本次置信度偏低，建议核对后再用。
- 链接被断词（如 `…BV1xx411 c7mD`）：如果整段就是链接，工具会自动去掉内部空格；混合文本不会擅自改动。

## 剪贴板里没有内容 / 提示"复制失败"

- 剪贴板正被其他程序占用：稍等重试（工具本身会重试 6 次并读回校验）。
- 部分"剪贴板增强"工具会互相抢占，可临时退出排查。
- 锁屏状态下系统剪贴板对整个会话不可用，解锁后恢复。

## 提示"未识别到文字"

- 该区域确实没有文字（纯色/黑屏/纯图标）；
- 或者对比度过低、文字被遮挡。换个区域或换一帧画面再试。

## 第一次取字特别慢

正常现象：PP-OCR 首次调用要加载模型（约 1.2 秒），之后每次约 0.4 秒。
为省内存，空闲 60 秒会释放模型，再次使用需要重新加载。

## 杀毒软件 / SmartScreen 提示未知发布者

本程序没有代码签名（个人开源项目），Windows 首次运行可能提示。
校验方式：对发布包计算 SHA256 与 Release 页面给出的值比对：

```powershell
certutil -hashfile SnapText.zip SHA256
```

不放心的用户可完全自行编译（见 [Architecture.md](Architecture.md#五构建与发布)）。

## 中文显示成方块 / 乱码

与"Unicode 支持"无关，通常是两种情况：

1. **引擎选错**：系统 OCR 需要中文语言包（设置 → 时间和语言 → 语言和区域 → 中文(简体) → 语言选项 → 安装"光学字符识别"）。建议直接用 PP-OCRv5；
2. **字体问题**：程序内文字使用系统字体（Microsoft YaHei UI / 等线），精简版系统可能缺失。

## 覆盖层卡住 / 关不掉

按 `Esc` 或**单击右键**均可取消。若鼠标键盘都无响应（极少见），
任务管理器结束 `SnapText.exe` 即可（不会留下垃圾文件）。

## 托盘图标不见了

Windows 会把不常用的托盘图标折叠进"隐藏的图标"区（▲）。把它拖出来固定即可。
若资源管理器重启过，图标可能会消失，重启 SnapText 即可。

## 开机自启怎么关

设置窗口取消勾选，或删除注册表项：`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下的 `SnapText`。

## 怎么彻底卸载

1. 托盘右键 → 退出；
2. 删除程序目录（自包含版就是整个 `dist\SnapText` 文件夹）；
3. 删除 `%LOCALAPPDATA%\SnapText`（配置与日志）；
4. 如开启过自启，删除上面提到的注册表项。

## 报告问题

请在 issue 里附上：

- 日志文件（`%LOCALAPPDATA%\SnapText\logs\app-*.log`，**注意先确认里面没有敏感内容**）；
- 你的 Windows 版本（`winver`）、是否多显示器/缩放比例；
- 复现步骤与预期行为。
